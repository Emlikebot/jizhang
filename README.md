# 记账（自用 PWA）

一个只给自己用的 iPhone 记账网页应用：添加到主屏幕后像 App 一样使用，离线可用，数据只保存在手机本地。

## 功能
- 记一笔：人民币 / 美元（自动汇率，可按银行实际扣款修改）、分类、支付方式、日期、备注；数字键盘支持 `+` `−` 连加
- 月度警戒线：80% 黄色提醒，超过后全屏红色提醒，首页卡片保持红色
- 统计：分类排行、每日支出、支付方式、近 6 个月对比
- 备份：导出 JSON（可恢复）/ CSV（Excel 打开），从备份恢复

## 更新版本
修改文件后，把 `sw.js` 第一行的版本号改大（例如 `jizhang-v1.0.1`），上传到 GitHub。
手机上打开 App →「设置」→「检查更新」。

汇率数据来自 [ExchangeRate-API](https://www.exchangerate-api.com)。
